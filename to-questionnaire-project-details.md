# Project Details — Problem / Idea / Result Questionnaire

**Purpose:** To define the copy and structure for the Project Details page, broken into Problem, Idea, and Result, so the page tells a clear, cinematic story instead of vague placeholders.

**From:** you · **To:** you (self-reflection) · **How your answers will be used:** Directly to draft the three sections for `src/app` project details route — headlines, body copy, visuals/captions, and proof points. No extra research needed after this.

## Context

You are building a Project Details page for lenard-designs (Obsidian Cinematic theme) where each project is shown in three chapters: the Problem you were hired to untangle, the Idea you pursued, and the Result you shipped.
